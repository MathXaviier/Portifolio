O objetivo desse arquivo é explicar o processo do Desafio de Projeto da DIO: Simulando um Malware de Captura de Dados Simples em Python e Aprendendo a se Proteger.

É importante frisar que esse projeito foi realizado em ambiente isolado e controlado, o que for descrito aqui foi utilizado unicamente para fins de conhecimento educacional.

Para aplicar o conhecimento mostrado em aula, foi utilizado o Virtual Studio Code. Ambos os códigos, tanto para o Ransomware, quanto para o Keylogger, foram criados em linguagem Phyton, onde foram necessárias utilizar algumas bibliotecas 

Começando com o Ransomware, ele se trata de um software malicioso que tranca os dados da vitima por meio de criptografia, o atacante exige um resgaste para que tais dados possam liberados por meio de uma chave para que possa descriptografar e assim recuperar os arquivos.
O script criado tinha como objetivo: gerar uma chave para criptografar os arquivos, realizar uma varredura no diretório para encontrar arquivos .txt, e logo em seguida trancá-los, substituindo eles por um arquivo ilegível e enviar uma mensagem a vitima, para causar o alerta quanto ao que estava acontecendo.

O Keylogger, é um software espião que grava em segundo plano tudo que é digitado no teclado. Primeiro, ele espera um comando inserido dentro do próprio código para que possa capturar o que é digitado, esse comando se dá ao pressionar qualquer tecla do teclado, podendo por meio deste mesmo código inserir comandos que filtrem algumas teclas tornando o conteúdo mais claro e fácio de ser lido, em seguida, registra convertendo o que foi teclado em texto e anexa a um arquivo oculto por exemplo, e por último extrai o arquivo, na aula por exemplo foi criado um e-mail para que fosse recebido a cada 60 segundos após o inicio da digitação, o conteúdo que foi digitado nos mais diversos programas dentro da máquina infectada.

Para que possamos nos proteger dessas ameaças é importante que tenhamos antivirus e firewalls instalados, atualizados e habilitados, os antivirus com análise comportamental passm a ser uma opção por conta de identificar padrões anormais dentro de máquinas infectadas e podendo identificar também softwares maliciosos não listados, autenticação de dois fatores também é uma defesa a ser considerada, por ser necessário a confirmação de acesso por meio de um código temporário gerado no celular, não só isso a conscientização do usuário para que não abra arquivos ou e-mails suspeitos, não sendo algo que possa ocorrer apenas no meio empresarial, mas também podendo surgir casos no meio pessoal.
